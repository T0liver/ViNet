- (constraint) SPEC.md decisions are final. Spine distills only calls that would let two epics diverge. No re-litigation.
- (direction) Altitude is initiative. Paradigm is pipes-and-filters with ports at the edges: Detector, InferenceBackend, FrameSource, LocationSource.
- (decision) AD-1: :app foreground service is the only composition root and the only capture pipeline. Replay and fakes implement those ports. UI observes and does not own tracks.
- (decision) AD-2: core-model has no deps. tracking, density, export depend only on core-model and have no Android APIs. inference, camera, location, data depend on core-model and not on each other. Nothing depends on app. Hilt stays in Android modules.
- (decision) AD-3: Shared types live in core-model. NormalizedBox is 0..1 of the source frame after letterbox removal. Manifest is the only source of classes, colors, thresholds, and preprocess. inference owns the one preprocess. outputFormat and backend select decoder and runtime.
- (decision) AD-4: Detector.detect is synchronous per frame. FrameSource and LocationSource are Flows. Camera uses keep-only-latest. Dropped frames are gaps; the tracker must not synthesize detections.
- (decision) AD-5: Pure modules return values. data repositories are the only writers of sessions, events, and image files. Best-frame bytes are written once when the track ends.
- (decision) AD-6: Section 5 wins the Room sketch: every Event stores packId and modelVersion. One imagePath and one thumbPath, no images table. Merge keeps the existing event and image. trackId stays the creating track.
- (decision) AD-7: Event lat/lon is the canopy point after mount offset, and EXIF GPS matches it. LocationManager is required. Fused location is optional and not on the app classpath. Meters and m/s. event.plotName is point-in-polygon only; session.plotName is the session label.
- (question) Join timebase is unspecified. frameTimestampNs and GeoFix.timestamp are not defined as the same clock. Asking the user. Epics must not each invent the interpolator.
- (decision) AD-8: Density counts unique events per meter, with no new coverage below a speed threshold. Severity is a separate box-area fraction. Alerts read segment results.
- (decision) AD-9: Offline-first. No telemetry, accounts, or sync. Optional user-visible pack download with SHA-256. MapLibre with local tiles. androidx.work. No Play services on the app classpath. Sideload APK. minSdk 26.
- (decision) AD-10: InferenceBackend hides bundled LiteRT, NCNN, or ONNX Runtime Mobile. Benchmark picks the backend and the tier. Benchmark inputs are on device. Thermal API is used on API 29+ and is a no-op below.
- (decision) AD-11: One immutable config object, passed in. Session stores the snapshot. Pure modules do not read preferences.
- (decision) AD-12: data mints opaque stable ids once. Stored instants are UTC epoch millis. Exporters render ISO-8601 UTC. Wall clock is not the frame/fix join key.
