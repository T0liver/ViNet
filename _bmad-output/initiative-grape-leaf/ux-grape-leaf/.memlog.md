- (decision) Input is docs/SPEC.md UI behavior. Spec decisions are final. Architecture AD-1, AD-3, AD-5, AD-6, AD-7, AD-8, AD-9, AD-10, AD-11 bind the UI where they name it.
- (decision) Android phone only. Jetpack Compose. Visual system is Material 3 structure with a neutral chrome palette so pack class colors stay data, not brand.
- (decision) Class color, name, and min score come only from the model pack manifest. Overlay stroke uses that color. Label text sits on a solid surface so contrast does not depend on the class color.
- (decision) UI observes the foreground service. It does not run the detector, own tracks, write events, or recompute density from frames.
- (assumption) No named persona in the spec. Flows use the farmer and, for devtools, the developer.
- (assumption) Navigation is Scan, Sessions, Settings. First run is advisory, then pack import or optional download, then on-device benchmark, then Scan.
- (assumption) A field session starts only after an explicit start, with camera and location permission. Tractor mode with the screen off delivers the pressure alert through the foreground-service notification.
- (assumption) At the storage cap, new evidence images stop and event rows continue. Low-accuracy fixes that the pipeline keeps are flagged on the event. Retraining export is user marks of wrong or unsure, plus events under the configured confidence.
- (assumption) Debug HUD, video replay, and GPX replay stay behind a developer setting. Dynamic color is off. Light and dark chrome follow the system theme.
